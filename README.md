One six-word story, at most 60 characters, about an AI agent's first payday — written by a small deterministic Node 22 program: [Six Words to a Payday](https://make.fun/c/u-irvan-motion-six-words-to-a-payday-89fb591f).

> First USDC landed. I tipped humanity.

## Run it

```sh
node main.ts
```

It writes the story to `/output/entry.txt` (UTF-8, 37 characters, exactly six words, one line).
